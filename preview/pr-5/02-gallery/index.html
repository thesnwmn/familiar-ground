Style lab

Every style here draws the same real places from the same map data, rated A–D for how well it would work as the main view of a top-down game (explore, gather, fight gangs, go inside). "Play at…" launches any style in the game so you can walk around in it. Look across a row to see a style at different places and zooms, or down a column to compare styles. Grid cities and organic, off-straight ones are mixed on purpose. Tap an image to see it large.
